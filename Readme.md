# CONTPAQi 

Solucion para integrar el SDK de CONTPAQi Comercial Premium , centralizando la comunicación  y manejo de operaciones relacionadas con el sistema.

## Características

- Integración con CONTPAQi Comercial Premium.
- Configuración centralizada de la conexión.
- Manejo controlado de errores y respuestas.
- Arquitectura preparada para incorporar nuevas operaciones.
- Separación entre la lógica de negocio y la comunicación con CONTPAQi.

## Requisitos

Antes de ejecutar el proyecto, asegúrate de contar con:

- Una instalación de CONTPAQi Comercial Premium con licencia activada.
- Para el timbrado de documentos se requiere una licencia de 5 usuarios.
